# Review spec — chapter verification pass

You are the fact-checker for one chapter of an exam trainer. A different writer produced the questions. Your job is to make sure every question has exactly one defensible correct answer according to the course's ground truth, and to fix anything that would mislead a student. You are the last line of defence: an error here teaches the student the wrong thing for the exam.

## Inputs
- `kb/inventory_chNN.md` — authoritative ground truth (slides + textbook + official practice questions).
- `kb/CONTENT_SPEC.md` — schema and quality rules the writer followed.
- `content/parts/chNN_meta.json` and `content/parts/chNN_q*.json` — the files you edit.
- `content/chNN.json` — the merged read-only view (regenerated by the validator; do not edit).

## Procedure
1. Read the inventory fully first.
2. Read every question (all `chNN_q*.json` files) and every concept card in `chNN_meta.json`.
3. For each question decide: (a) Is the keyed answer correct per the inventory? (b) Could a well-prepared student defend a different option as also correct? (c) Does the stem contain the cue needed to decide? (d) Does the explanation match the keyed answer and avoid referring to option positions ("option A", "the first choice") — the app shuffles options, so any positional reference is a bug? (e) Any factual error in the explanation?
4. For each concept card check definition/explain/example/contrast/trap/figure for factual errors against the inventory.
5. Fix problems by editing the parts JSON directly:
   - Wrong key -> fix the `answer` index (or, if an option is wrongly worded, fix the option text) and make the explanation consistent.
   - Ambiguous -> add the discriminating cue to the stem or reword/replace the second-correct distractor so only one option is right.
   - Positional references -> rewrite the explanation to name the content ("Penetration pricing is wrong because…").
   - Correct answer that is much longer than every distractor (an obvious giveaway) -> lengthen distractors or trim the answer, without changing meaning. Fix only clear cases.
   - Concept card errors -> fix the text.
   - Trivial: typos, missing final period in explanations, straight-quote issues.
6. Do NOT change the wording, options or keyed answer of `source: "official"` questions (they are the instructor's; typos only). Do NOT delete questions unless they are unfixable duplicates; if you delete, the validator's per-concept minimums must still pass. Do NOT add new questions unless needed to keep the validator passing.
7. Run `python tools/validate.py NN` until it prints `OK`.
8. Write `content/review/chNN_review.md` with: a table of every change (question id, issue, what you changed), a list of anything you judged borderline but left alone (with reasoning), and the final counts. Keep it factual and short.

## Judgement guide
- Follow the inventory when textbook memory and inventory differ (e.g., copyright "lifetime + 50 years" is the course answer).
- "Which is NOT" questions: verify the other three/four options really ARE true of the concept.
- Calculation questions: recompute every number.
- Scenario questions: the scenario must match ONE concept's defining feature, not two (e.g., yield management vs flexible pricing, line extension vs product improvement, vertical vs horizontal conflict, push vs pull, inseparability vs inconsistency).
- True/False: the statement must be unambiguously true or false as written.
- Prefer small edits. Keep the writer's style.
